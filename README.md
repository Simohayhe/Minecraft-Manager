# ⚡ Beacon — Minecraft サーバー管理アプリ

Minecraftサーバーをかんたんに立てて管理できる、Windows向けのデスクトップアプリです。
難しいコマンドやファイル操作は不要。**インストールから起動まで、すべてGUI操作だけで完結します。**

> **動作環境：Windows 10 / 11（64bit）**

## Beaconでできること

| 機能 | 内容 |
|------|------|
| **Javaの自動管理** | Java 8 / 17 / 21 / 25 をアプリ内でインストール・管理。システムにインストール不要 |
| **Fabricサーバー** | Minecraftの人気MODローダー。Modを入れて遊ぶのに最適 |
| **Paperサーバー** | 高パフォーマンスなサーバー。Pluginをたくさん入れたいときに便利 |
| **クラスター（Velocity）** | 複数のサーバーを1つに繋ぎ、ロビー・ゲームサーバーを切り替えられる仕組みを作れる |
| **Mod / Plugin管理** | ライブラリフォルダを登録してチェックひとつで適用 |
| **プレイヤー管理** | オンラインのプレイヤー確認・OP権限付与・テレポート・Kickを画面から操作 |
| **パフォーマンス監視** | 起動中のサーバーのCPU使用率・メモリ・ディスク容量をリアルタイム表示 |
| **UPnP対応** | ルーターのポート開放をアプリから自動設定 |
| **自動再起動** | サーバーがクラッシュしたとき自動で再起動 |

## インストール

1. [Releases](https://github.com/Simohayhe/Minecraft-Manager/releases) から最新の `.exe` をダウンロード
2. ダウンロードした `.exe` をダブルクリックしてインストール
3. インストール完了後、デスクトップのショートカットか、スタートメニューから **Beacon** を起動

## 最初にやること（初期設定）

アプリを初めて起動したら、**サーバーファイルをどこに保存するか**を設定します。

1. 左のサイドバーから **「⚙ 設定」** を開く
2. 一番上の **「サーバーベースフォルダ」** の「フォルダ選択」をクリック
3. サーバーファイルを置きたいフォルダを選ぶ（例：`C:\MinecraftServers`）
4. 選択したフォルダが表示されれば完了

> **ヒント：** このフォルダの中に、各サーバーのフォルダが自動で作成されます。
> 空のフォルダを新しく作って指定するのがおすすめです。

## Javaのセットアップ

Minecraftサーバーを動かすには **Java** が必要です。
Beaconはアプリ内でJavaを管理できるので、別途インストールする必要はありません。

1. **「⚙ 設定」** → **「☕ Java管理」** タブを開く
2. 使いたいJavaバージョンの **「インストール」** ボタンをクリック
   - Minecraft 1.21以降 → **Java 21**（推奨）
   - Minecraft 26.1以降 → **Java 25**
   - 古いバージョンのMod対応 → **Java 17** または **Java 8**
3. ダウンロード・インストールが自動で完了します

> **どれを入れればいい？**
> 迷ったら **Java 21** だけ入れておけば、最新のMinecraftはほぼすべて動きます。

### 複数バージョンの共存

Beaconは複数のJavaバージョンを同時に管理できます。
サーバーごとに使うJavaを個別に指定することも可能です（サーバー設定の「Java」欄から選択）。

## スタンドアロンサーバー

### スタンドアロンとは？

**1台だけのシンプルなMinecraftサーバーです。**
友達と一緒に普通にMinecraftをマルチプレイしたいなら、これを使いましょう。

```
プレイヤー → [スタンドアロンサーバー]
```

### サーバーを作る

1. 左サイドバーの **「🖥 サーバー管理」** を開く
2. 上部のタブで **「スタンドアロン」** を選択
3. **「＋ サーバー追加」** をクリック
4. 以下を設定して「次へ」または「作成」をクリック：

| 項目 | 内容 |
|------|------|
| **サーバー名** | 自分で管理するための名前（なんでもOK） |
| **ポート番号** | 外から接続する番号。初期値の `25565` のままでOK |
| **サーバー種別** | Fabric（Mod向け）/ Paper（Plugin向け） |
| **Minecraftバージョン** | 遊びたいバージョンを選ぶ |

5. サーバーカードが表示されたら **「インストール」** ボタンをクリック
6. 自動でサーバーファイルがダウンロード・インストールされます（数分かかります）
7. インストール完了のメッセージが出たら準備完了！

### サーバーを起動・停止する

- **起動**：サーバーカードの **「起動」** ボタンをクリック
  → ステータスが「起動中...」→「● 稼働中」になれば成功
- **停止**：**「停止」** ボタンをクリック
- **再起動**：**「再起動」** ボタンをクリック（停止→5秒後に自動起動）

#### 接続方法（サーバーに入る）

1. Minecraftを起動
2. 「マルチプレイ」→「サーバーを追加」
3. **サーバーアドレス**に以下を入力：
   - **同じPC内から接続**：`localhost` または `127.0.0.1`
   - **同じWi-Fi内の別PCやスマホから**：BeaconのサーバーカードにあるローカルIPを入力
     （例：`192.168.1.10:25565`）
   - **インターネット越しの友達から**：Beaconトップ右上に表示される **「🌐 Global IP」** を教える
     （ポート開放が必要です → [ポート管理・UPnP](#ポート管理upnp) を参照）

#### ログ・コンソールを見る

サーバーカードをクリック → **「ログ」** タブでリアルタイムのログを確認できます。
ログ画面の下のテキストボックスにコマンドを入力して Enter を押すと、サーバーにコマンドを送れます。

```
例：/op プレイヤー名　（管理者権限を付与する）
例：/give プレイヤー名 diamond 64　（アイテムを渡す）
```

### 設定を変える

サーバーカードをクリック → **「設定」** タブ

| 設定項目 | 説明 |
|----------|------|
| **難易度** | ピースフル / イージー / ノーマル / ハード |
| **ゲームモード** | サバイバル / クリエイティブ / アドベンチャー |
| **最大プレイヤー数** | 同時接続できる人数 |
| **JVMメモリ** | サーバーに割り当てるメモリ量（GB）。プレイヤーが増えるほど多く必要 |
| **ホワイトリスト** | ONにすると登録した人だけ接続できる |
| **RCON** | 外部ツールからコマンドを送る機能 |

> **メモリの目安：**
> 2〜4人 → 2GB、5〜10人 → 4GB、Modをたくさん入れる場合 → 6GB以上

### Modを入れる（Fabricのみ）

サーバーカードをクリック → **「Mod」** タブ

事前に **「📦 Mod管理」** でModのフォルダを登録しておく必要があります。

1. 「📦 Mod管理」→「＋ Modフォルダを登録」でModが入ったフォルダを追加
2. サーバーの「Mod」タブを開く
3. 使いたいModにチェックを入れて **「適用」** をクリック
4. サーバーを再起動するとModが有効になります

> **注意：** サーバー側のModとクライアント（自分のMinecraft）側のModは**両方**揃える必要があります。

### バックアップ・ワールド削除

サーバーカードをクリック → 「設定」タブ下部

- **バックアップ**：ワールドデータを別フォルダに丸ごとコピーします
- **ワールド削除**：ワールドデータを削除してまっさらにします（2回確認があります）

## クラスターサーバー

### クラスターとは？

**複数のMinecraftサーバーを1つのプロキシ（Velocity）で繋いだ構成です。**
プレイヤーは1つの接続先で、コマンド（`/server ロビー` など）を使って複数のサーバーを行き来できます。

```
プレイヤー → [Velocity（入口）] → [ロビーサーバー]
                              ↓
                         [ゲームサーバー1]
                              ↓
                         [ゲームサーバー2]
```

**こんなときに使う：**
- 「ロビー」「サバイバル」「ミニゲーム」を分けたい
- たくさんの人数に対応したい
- サーバーを止めずに別ワールドに移動させたい

### クラスターを作る

1. 「🖥 サーバー管理」を開く
2. 右上の **「＋ クラスター追加」** をクリック
3. クラスター名を入力（例：`MyServer`）
4. **Velocityポート**を設定（プレイヤーが接続する番号。デフォルト `25577`）
5. 「作成」をクリック

これでVelocityプロキシのセットアップが自動で行われます。

### サーバーを追加する

クラスタータブ内の **「＋ サーバー追加」** をクリック

| 項目 | 内容 |
|------|------|
| **サーバー名** | Velocityから見た名前（英数字推奨）例：`lobby`、`survival` |
| **ポート番号** | このサーバー個別のポート。外に公開しなくてよい（例：25565、25566...） |
| **サーバー種別** | Fabric（Mod向け）/ Paper（Plugin向け） |
| **Minecraftバージョン** | 遊びたいバージョン |

サーバーを追加したら、各サーバーカードの **「インストール」** をクリックしてファイルをダウンロードします。

> **クラスター内のサーバーのポートは外部公開不要です。**
> プレイヤーはVelocityのポート（25577）だけに接続します。

### 起動・停止する

- **全体起動**：クラスタータブ右上の **「クラスター起動」** ボタン
  → VelocityとすべてのサーバーがまとめてONになります
- **個別起動**：各サーバーカードの「起動」ボタンから個別に操作できます
- **Velocity停止**：「クラスター停止」ボタン（サーバーが全て止まってから押してください）

#### 接続方法

プレイヤーは **Velocityのポート** に接続します。

```
[Velocityのグローバルip]:25577
```

Beaconトップ右上の **「🌐 Global IP」** を確認して、`:25577` を付けて教えてください。

#### サーバー間の移動

プレイヤーがゲーム内でコマンドを打つと移動できます：

```
/server サーバー名
例：/server lobby
例：/server survival
```

### Velocity設定

クラスタータブの **「Velocity」** タブから設定できます。

| 項目 | 説明 |
|------|------|
| **プロキシポート** | プレイヤーが接続するポート番号 |
| **MOTD** | サーバー一覧に表示される説明文 |
| **最大プレイヤー数** | 表示上の最大人数 |
| **転送モード** | `modern`（推奨）のまま変えなくてOK |
| **フォワーディングシークレット** | Velocityとサーバー間の認証キー。自動で管理されます |

> **フォワーディングシークレット**は、Velocityとバックエンドサーバーの認証に使うキーです。
> Beaconが自動で生成・同期するので、手動で変更する必要はありません。

### コンソール

クラスタータブの **「コンソール」** タブで、Velocityと各サーバーのログをタブ切り替えで確認できます。

### Mod・Plugin管理

- **「Mod」タブ**：クラスター内の全Fabricサーバーに共通で適用するModを選択
- **「Plugins」タブ**：Velocityのプラグインを選択・適用
- 各サーバー個別のModはサーバーカードをクリック → 「Mod」タブから管理

### プレイヤー管理

クラスタータブの **「プレイヤー」** タブで、今オンラインのプレイヤーを管理できます。

| 操作 | 内容 |
|------|------|
| **OP付与 / 剥奪** | 全サーバー一括、またはサーバー別に設定できます |
| **テレポート** | 特定のサーバーの指定座標にテレポートさせます |
| **Kick** | サーバーから強制退出させます |
| **UUID取得** | プレイヤーのUUIDをMojang APIから取得します |

### インベントリ共有（Invsync）

クラスター内の複数サーバー間で**インベントリ（持ち物）を同期**する機能です。

1. 各サーバーカードをクリック → **「🔗 共有設定」** タブ
2. Invsyncのバージョンを選択
3. トグルをONにする（自動でモジュールがインストールされます）

> **必要なもの：** MariaDB（データベース）が起動していること。
> → 「設定」→「🗄 SQL / DB」タブから設定・起動できます。

### データベース（MariaDB）

インベントリ共有などのデータを保存するために使います。

#### セットアップ手順

1. **「⚙ 設定」** → **「🗄 SQL / DB」** タブを開く
2. **「MariaDBをインストール」** をクリック
3. **パスワード** を設定（後から変更しづらいので覚えておきましょう）
4. インストール完了後、**「DB起動」** をクリック
5. ステータスが「稼働中」になれば完了

#### クラスター用スキーマ

各クラスターには専用のDBスキーマが必要です。

- クラスタータブ → **「🗄 DB」** タブ → **「スキーマを作成/確認」** をクリック
- DBが起動していればクラスター作成時に自動で作成されます

## パフォーマンス監視

起動中のサーバーのリソース使用状況を確認できます。

### 確認方法

**クラスター内のサーバー：**
クラスタータブ → **「📊 パフォーマンス」** タブ

**スタンドアロンサーバー：**
サーバーカードをクリック → **「📊 パフォーマンス」** タブ

**全サーバー一覧：**
「⚙ 設定」 → **「📊 パフォーマンス」** タブ

### 表示内容

| 項目 | 内容 |
|------|------|
| **CPU** | サーバープロセスのCPU使用率（3秒ごとに自動更新） |
| **メモリ** | 使用中のメモリ / 確保しているメモリ（3秒ごとに自動更新） |
| **ディスク** | サーバーフォルダ全体のサイズ（5分ごとに自動更新・🔄ボタンで手動更新） |

## ポート管理・UPnP

### ポート管理

**「⚙ 設定」** → **「🔓 ポート管理」** タブ

登録されているサーバーのポート番号一覧を確認できます。
同じポートが重複している場合は警告が表示されます。

### UPnP（ポートの自動開放）

インターネット越しに友達と遊ぶには、ルーターのポートを開放する必要があります。
UPnP対応のルーターであれば、Beaconから自動でポートを開放できます。

1. **「🔦 診断」** を開く
2. 「UPnP」セクションの **「ポートを開放」** ボタンをクリック
3. 開放したいポートを入力して実行

> **UPnPが使えない場合：**
> ルーターの管理画面から手動でポートフォワーディングの設定が必要です。
> 設定方法はご利用のルーターのマニュアルを参照してください。

## 既存サーバーをインポートする

すでに手元にあるサーバーフォルダをBeaconに取り込めます。

### スタンドアロンサーバーのインポート

1. 「サーバー管理」右上の **「インポート」** ボタンをクリック
2. 「スタンドアロンとしてインポート」を選択
3. 既存のサーバーフォルダを選択
4. 自動でスキャンして設定を読み取ります

### クラスターのインポート

1. 「インポート」→「クラスターとしてインポート」
2. クラスターのフォルダ（複数のサーバーフォルダとvelocityフォルダが入ったフォルダ）を選択
3. 既存の構成を自動で認識します

> 既存のサーバーを再スキャンしたい場合は、クラスタータブの **「再スキャン」** ボタンを使ってください。

## よくある質問

### Q. サーバーが起動しない

**A. よくある原因と対処法：**

1. **Javaがインストールされていない**
   → 「設定」→「Java管理」から対応するバージョンをインストールしてください

2. **ポートがすでに使われている**
   → 別のサーバーやアプリが同じポートを使っていないか確認してください

3. **メモリが足りない**
   → JVMメモリの設定を下げてみてください（PCの空きメモリより少ない値に設定）

4. **サーバーファイルが壊れている**
   → サーバーを削除して再インストールしてください

---

### Q. 友達がサーバーに接続できない

**A. 確認するポイント：**

1. サーバーが起動しているか確認
2. ポートが開放されているか確認（「診断」→ UPnPでポート開放、またはルーター設定）
3. 伝えたIPアドレスとポートが正しいか確認
4. Windowsファイアウォールがブロックしていないか確認

---

### Q. クラスターでスキンが表示されない

**A.** クラスター構成では以下の設定が必要です：

- Velocity側：`online-mode = true`（Beaconが自動設定）
- 各サーバー側：`online-mode = false`（Beaconが自動設定）
- 転送モード：`modern`（デフォルト設定）

これらはBeaconが自動で設定しますが、手動で変更した場合は元に戻してください。

---

### Q. Invsync（インベントリ共有）が動かない

**A. 確認するポイント：**

1. 「設定」→「SQL/DB」でMariaDBが**起動中**になっているか
2. クラスタータブ→「DB」タブでスキーマが作成されているか
3. 各サーバーの「🔗 共有設定」タブでInvsyncがONになっているか
4. サーバーを再起動してみる

---

### Q. アプリを更新するには？

**A.** 新しいバージョンが出ると、アプリ起動時に自動で通知が届きます。
画面の指示に従って更新してください。
